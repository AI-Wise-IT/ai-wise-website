# AI Wise Website

This repository contains the static website for AI Wise.

## Current Site

The current site is a temporary coming-soon page for `https://aiwise.it.com`.

Files:

- `index.html`: Static landing page.
- `CNAME`: GitHub Pages custom domain configuration.
- `assets/profile-picture-professional.jpg`: Profile image used on the landing page.
- `assets/favicon.svg`: Browser favicon.

## Local Preview

Open `index.html` in a browser.

## GitHub Pages

The repository includes a GitHub Actions workflow at `.github/workflows/pages.yml` that publishes the site to GitHub Pages.

The `CNAME` file configures GitHub Pages to serve the site at `https://aiwise.it.com`.

In GitHub, set Pages to deploy from GitHub Actions.
