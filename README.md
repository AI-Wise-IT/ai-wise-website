# AI Wise website

The public website for AI Wise, at <https://aiwise.it.com>.

One page, in Dutch and English, covering what AI Wise stands for, who is behind
it, and how to get in touch. No offer, no pricing, no scan. The requirements are
in [docs/prd.md](docs/prd.md).

## Stack

- [Astro](https://astro.build) 7, static output
- Design tokens and assets from the AI Wise design system in Claude Design;
  see [docs/design-system-import.md](docs/design-system-import.md)
- Vercel Web Analytics, cookieless, served from this site's own origin
- Hosted on Vercel

TypeScript is held at 6 on purpose: `@astrojs/check` accepts `^5 || ^6`, so
TypeScript 7 would break `npm run check`. Everything else tracks latest stable.

### Content-Security-Policy

The policy is generated by Astro (`security.csp` in `astro.config.mjs`), which
hashes the inline stylesheet and the analytics script so `'unsafe-inline'` is not
needed. Two consequences worth knowing before you edit a component:

- **No inline `style` attributes.** CSP hashes cover stylesheets, not style
  attributes, so an inline style is blocked outright. Put it in `site.css`.
- **The `<Analytics />` component belongs at the end of `<body>`,** not in the
  head where Vercel's docs put it. It renders a `<vercel-analytics>` custom
  element, and an unknown element in the head makes the parser close the head
  early; the CSP meta tag then lands in the body, where it is ignored.

After changing anything in the head or adding a script, load a page from
`npm run preview` and check the console for CSP violations.

### The hero and the header

The hero sits on a photograph, art-directed in `Hero.astro`: a 16:9 crop on
landscape-shaped screens and a 4:5 crop on portrait ones, with a near-black
layer in `site.css` that keeps the text readable over the light sky. The weave
is no longer used on the website.

On the home page the header is transparent over the photograph at the top and
turns solid once the page scrolls. That is a CSS scroll-driven animation, not
JavaScript, and the solid header is the default: a browser without
`animation-timeline` support simply keeps it. The minifier folds
`animation-timeline` into the `animation` shorthand if they share a rule, and
Chromium then drops the declaration, so keep them in separate rules.

## Running it

```bash
npm install
npm run dev
```

The dev server binds to IPv6 by default, which some tools cannot reach. To force
IPv4:

```bash
npm run dev -- --host 127.0.0.1
```

Build and preview the production output:

```bash
npm run build
npm run preview
```

Type-check the Astro components:

```bash
npm run check
```

```
  styles/site.css  what this site adds on top

```

## Editing the copy

All text lives in [`src/content/copy.ts`](src/content/copy.ts), typed so both
languages stay in step. A text change is not a code change.

The copy follows the voice rules in the design system's `readme.md`, under
"Content fundamentals". In short: first person singular as Simon, sentence case,
concrete before clever, claims only with a qualification. No hype vocabulary, no
experience claims, no statements about time saved or safety, no emoji, no
em-dashes. The tagline stays English and untranslated in both languages.

## Discoverability

The site is meant to be readable by search engines and by AI search and answer
systems alike:

- Static HTML, so nothing essential needs JavaScript to appear
- `robots.txt` allows regular crawlers, AI search crawlers and user-triggered
  fetchers, and disallows model-training crawlers. Those are separate choices:
  the site stays fully findable and citable in AI-assisted search either way
- `llms.txt` gives a plain orientation to what AI Wise is and is not
- JSON-LD for the business, the person and the site
- One canonical host, no trailing slashes, `hreflang` for both languages plus
  `x-default`, and a sitemap that carries the alternates
